# Special Topics Project for a trige cve
A machine learning-based system for prioritizing Common Vulnerabilities and Exposures (CVEs).

## Project Scope
The system predicts the probability that a CVE belongs to the CRITICAL severity class and ranks CVEs to support security analyst triage.
The system assists prioritization.

## Phase 1
- Data validation and feature engineering.
- Model training and evaluation.
- CVE ranking.
- Experiment tracking with MLflow.
- Packaging and Docker deployment.
